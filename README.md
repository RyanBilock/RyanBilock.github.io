# Ryan Bilock — Portfolio

Static one-page portfolio. No build step.

## Files
- `index.html` — the whole site (styles inline; fonts from Google Fonts)
- `resume.pdf` — linked from the "Download resume" button

## Publish on GitHub Pages
1. Create a public repo named `<your-github-username>.github.io`.
2. Upload `index.html` and `resume.pdf` to the repo root.
3. Repo **Settings → Pages** → Source: *Deploy from a branch* → `main` / root → Save.
4. The site goes live at `https://<your-github-username>.github.io` within a few minutes.

## Updating the resume
Replace `resume.pdf` with the new export, keeping the same file name, so the button keeps working.

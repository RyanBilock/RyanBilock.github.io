03 · Projects

Selected work

P-01

SWIFT-UAV 6-DOF Flight-Dynamics Simulation

RoleUndergraduate researcher
LabAdaptive Real-Time Systems Lab
StatusIn development

Problem

SWIFT is an open-source fixed-wing UAV research platform. The team needed a physics-based model of the aircraft to test flight conditions and support future guidance and control work before committing hardware to the air.

Approach

I built a hybrid Simulink architecture: an Aerospace Blockset 6-DOF equations-of-motion core, with MATLAB Function blocks calling shared force-and-moment code. The aerodynamic coefficient buildup and propulsion model are derived from first principles. Mass is tracked as a component budget that sums to the all-up weight, and any number not yet measured runs as a tagged estimate, so the model works today and tightens as test data comes in.
